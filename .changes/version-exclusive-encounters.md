Games with more than one version now have a Version menu on the tracker, from Red, Blue and Yellow to Brilliant Diamond and Shining Pearl. Pick the version you're playing and each location offers only the Pokémon found there in that version, such as Pikachu as Yellow's only starter, with Bulbapedia as the source. "All versions" keeps every encounter, as before, and custom games don't have the menu.
